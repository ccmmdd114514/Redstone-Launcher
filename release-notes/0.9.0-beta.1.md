# 0.9.0-beta.1（Beta 测试版）

发布日期：2026-10-02

## 本次变更

首个对外发布版本，此前全部为开发期未打包状态。

### 新增

- 拉取官方版本清单（`version_manifest_v2.json`），支持安装任意官方版本
- 解析 version.json 的 `arguments`：rules 求值 + 变量展开，主类名不硬编码
- 下载 client.jar、依赖库与资源文件：并发 16、重试 3 次、sha1 与 size 双重校验
- 原生库解压：含 zip-slip 防护，且只取当前平台架构的变体
- 本机 Java 探测与自动选版，支持精确匹配与就近向上
- 离线账号：昵称经 uuid5 派生稳定 UUID
- 官方源优先、BMCLAPI 镜像兜底，可用 `--mirror` 强制切换
- 多版本实例隔离：各版本独立存档与模组，共享库与资源以避免重复下载
- 启动日志落盘到 `logs\mcl-<时间戳>.log`
- 八个命令：`list` / `instances` / `install` / `launch` / `remove` / `logs` / `doctor` / `java`
- 分发入口：`redstone.bat`（双击不闪退）与 `add-to-path.bat`（写入用户 PATH）

### 修复

- 无（首个版本）

### 变更

- 无（首个版本）

## 验证情况

验证环境：Windows 11（内部版本 26200），Java 21.0.12.1，Rust 1.99.0（gnu 工具链）。

| 验证项 | 结果 |
| --- | --- |
| `redstone --version` | 输出 `redstone 0.9.0-beta.1` |
| `redstone doctor` | 4 套 Java 全部识别；三个目录均可写；官方清单可达（917 个版本，671 ms） |
| `redstone install 1.21.8` | 97 MB 依赖库 + 428 MB 资源，4271 个文件零校验失败 |
| 二次 `install 1.21.8` | 4271 个文件全部命中缓存跳过 |
| `redstone launch 1.21.8` | 游戏窗口标题为 `Minecraft 1.21.8`，进入主界面，退出码 0 |
| 中文昵称（阿强） | 启动参数与游戏内均显示正常，无乱码 |
| 实例隔离 | 实例目录自动生成 saves / logs / options.txt，共享区未重复下载 |
| 启动日志 | 生成 `mcl-<时间戳>.log`，`redstone logs` 可正确读回 |
| 分发包解压 | 解压后 `redstone.exe` 可直接运行，四个必需文件齐全 |

## 已知问题与局限

- 仅验证过 1.21.8；1.12.2、1.16.5 等老版本的兼容分支尚未实测
- 无进程锁：重复启动同一版本时会因原生库目录被占用而失败
- 无 JRE 自动下载：缺少所需 Java 版本时只提示，不自动下载
- 仅支持离线账号；微软正版登录与 LittleSkin 尚未实现
- 不支持模组加载器（Fabric / NeoForge / Forge）与整合包
- 下载无失败阈值：源异常时会按重试次数硬扛到底，不会提前中止
- 资源索引（`assetIndex`）下载后未校验 sha1
