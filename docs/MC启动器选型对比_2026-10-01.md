## 二、按使用场景的推荐结论

| 使用场景 | 首推 | 理由 |
| --- | --- | --- |
| 新手入门（Windows、中文界面、国内网络） | **PCL2** | 中文界面、内置国内镜像源下载快；模组、Forge/Fabric、Java 环境、整合包都是一键式；官网与开源仓库均可核对，无广告无捆绑。只吃原版且有正版账号时再用官方启动器。 |
| 模组整合包玩家 | **Prism Launcher** | 内置 Modrinth / CurseForge 浏览安装，整合包一键更新；每个整合包独立实例与独立 Java，崩一个不牵连其他；无 Overwolf、无广告。若整合包多来自国内社区、下载偏慢，可改用 PCL2 或 HMCL（自带镜像源）。 |
| 多版本 / 多实例管理 | **HMCL** | 老版本（如 1.7.10、1.12.2）兼容与恢复良好，实例管理轻量，支持导出 HMCL/MultiMC 整合包便于迁移；跨平台（Windows/macOS/Linux），换系统不用换启动器。需要严格隔离与多人多账号并行时再上 Prism。 |
| 性能优化需求 | **Prism Launcher**（启动器层面）＋ **Sodium/Iris + OptiFine**（游戏层面） | 启动器层面 Prism 用 Qt 编写、常驻占用低，且 JVM 内存与 GC 参数可按实例单独调（如设置 `-Xmx`、ZGC/Shenandoah）。实际帧率提升靠游戏侧：Fabric 装 Sodium + Iris 光影，Forge 老版本用 OptiFine，内存分配建议取物理内存的 50%–70%。 |

## 三、已被剔除的方案（停更 / 归档 / 有风险）

| 项目 | 状态 | 处理 |
| --- | --- | --- |
| TLauncher 及各类"破解正版"启动器 | 绕过正版验证，违反用户协议；安全机构已标记 `PUP.Optional.TLauncher`，存在盗号与捆绑风险 | **直接剔除** |
| MultiMC | 主线仓库（MultiMC/Launcher）最后一次发布为 0.6.14，时间 2021-12 | 新用户**不建议安装**，改用同血统的 Prism Launcher（官方迁移路径） |
| GDLauncher | GitHub 主仓库已标记 ARCHIVED | 新用户**不推荐**，继任项目为 GDLauncher Carbon（预览阶段） |
| HMCL-PE | Android 版 2026 年起停止维护 | 剔除，移动端改用 FCL / Pojav / ZL2 |
| BakaXL 3.x | 官方路线图标注"仅安全维护"，4.0 仍为预览频道，且非完全开源 | 不作为首推，可留作美化向备用 |
| 各类下载站聚合页（非官方软件站、网盘二次分发） | 常植入广告、捆绑安装器或篡改包 | **一律不走**，只从官网 / GitHub Releases 下载并核对 SHA-256（HMCL、Prism 官方页面均提供校验值） |

## 四、下载安全性提示

1. 只从官方站点或项目 GitHub 仓库获取安装包；HMCL、Prism、ATLauncher 均在发布页给出 SHA-256，下载后建议校验。
2. 第三方启动器只是"入口"，仍需正版授权：离线模式不等于绕过购买，进入正版验证服务器必须拥有合法授权。
3. 登录只走微软官方 OAuth 授权窗口；凡要求直接输入微软/Minecraft 明文密码的第三方启动器，一律视为高风险。
4. Windows SmartScreen 报"未知发布者"常见于未签名的开源软件，先验明下载页是否为 prismlauncher.io、hmcl.huangyuhui.net、pcl2.aoe.top 等官方域名后再放行。
